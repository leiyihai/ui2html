# 动画工具第一版实现清单

分支：codex/animation-tool

## 已实现

### 动画数据与时间轴

- 节点动画片段：时长、延迟、循环、方向、自动播放。
- 关键帧轨道：位置、缩放、旋转、透明度、视觉宽度、视觉高度。
- 线性、缓入、缓出、缓入缓出。
- 时间轴播放、暂停、回到开始、拖动时间指针。
- 手动添加和删除关键帧。
- 动画预览实时驱动画布节点。
- 旋转、位置、尺寸、缩放和透明度会作用到当前预览。

### AI 动画生成

- 动画工作区内直接输入自然语言提示词。
- 支持“当前节点”和“整个场景”两种生成范围。
- AI 请求同时携带：
  - 结构化节点与现有动画数据；
  - 当前界面渲染参考图；
  - 可调用的内置特效清单。
- AI 结果先进入审查区，不会直接改工程。
- 支持查看建议数量、置信度、目标节点和生成原因。
- 用户确认后批量应用动画片段。
- 已有动画片段不覆盖，冲突时生成新的片段 ID。
- AI 服务不可用时，自动使用本地动画适配器生成可审查草稿。

### 特效库适配层

- 内置淡入、弹性出现、向上滑入、向左滑入、强调呼吸、轻微抖动。
- 特效转换为 UI2HTML 通用关键帧，不把网页运行时库写入目标引擎 UI JSON。
- 每个特效记录适配版本、来源和许可证信息。
- 当前适配层参考 anime.js 的时间轴与缓动设计；导出结果保持引擎无关。

### 动画流程编辑

- 创建、删除和重命名界面级动画流程。
- 流程触发方式：
  - 手动；
  - 显示时；
  - 点击时；
  - 悬停时；
  - 选中时；
  - 数值变化时。
- 将不同节点的动画片段加入同一流程。
- 编辑流程步骤的开始时间和持续时间。
- AI 可以同时生成流程草稿，审查后再加入工程。

### 工程与导出

- 动画片段和流程保存到 .ui.json 工程内部。
- 撤销/重做包含动画修改。
- HTML 导出包含稳定节点 ID、动画片段和动画流程数据，便于继续交给 AI 分析。
- 自研引擎 UI JSON 不写入 UI2HTML 内部交互语义和动画流程。
- 删除节点时会清理无效的九宫格候选和动画流程步骤。
